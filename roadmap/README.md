# Roadmap

The roadmap describes the current direction of ChowderAI Lab.

It provides visibility into the capabilities we are developing, the initiatives we are pursuing, and the milestones that define our progress.

Unlike Foundation, the roadmap evolves continuously.

## Documents

| Document | Description |
|----------|-------------|
| `direction.md` | The current direction of the organization. |
| `capabilities.md` | The capabilities we are developing. |
| `initiatives.md` | The active initiatives and products. |
| `milestones.md` | Major milestones and achievements. |

The roadmap is directional, not contractual.

It evolves as the organization learns.
