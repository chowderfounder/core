# Contributing

Thank you for contributing to ChowderAI Lab.

## Principles

Before contributing, please make sure your changes:

- Solve a real problem.
- Keep the repository simple.
- Improve clarity.
- Avoid unnecessary documentation.
- Follow existing conventions.

## Pull Requests

Every contribution should explain:

- What changed.
- Why it changed.
- How it improves the organization.

Small, focused pull requests are preferred.
