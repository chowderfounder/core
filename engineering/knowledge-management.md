# Knowledge Management

Knowledge is one of the organization's most valuable assets.

Documentation exists to preserve and share that knowledge.

## Principles

- Documentation follows reality.
- Every document answers one question.
- Keep documents small and focused.
- Prefer reusable knowledge over implementation details.
- Record significant decisions.
- Remove or update outdated documentation.

## Documentation

Documentation should explain:

- Why
- What
- When necessary, how

Avoid documenting temporary implementation details.

## READMEs

A README introduces a repository.

It is not the repository documentation.

## ADRs

Architectural Decision Records are created only for decisions with long-term impact.

## Evolution

Documentation evolves together with the software.
