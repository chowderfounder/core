# Source Control

Source control preserves the history of the organization and enables safe collaboration.

## Principles

- Keep changes small and focused.
- Prefer short-lived branches.
- Protect the main branch.
- Review before merging.
- Automate repetitive workflows.

## Standards

| Area | Standard |
|------|----------|
| Version Control | Git |
| Commit Convention | Conventional Commits |
| Branch Strategy | Short-lived branches with Pull Requests |
| Versioning | Semantic Versioning |
| Changelog | Keep a Changelog |
| Releases | GitHub Releases |

## Repository Conventions

Every repository should include:

- README
- LICENSE
- CHANGELOG
- CONTRIBUTING

Additional files are introduced only when they provide long-term value.

## Automation

Repository workflows should be automated whenever practical.
