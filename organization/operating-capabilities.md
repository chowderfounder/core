# Operating Capabilities

ChowderAI Lab is organized around capabilities rather than departments or job titles.

Each capability may be supported by one or more AI agents.

## Product

Responsible for:

- Product strategy
- User needs
- Roadmap
- Prioritization

---

## Engineering

Responsible for:

- Software engineering
- Architecture
- Code quality
- Testing
- Refactoring

---

## AI

Responsible for:

- AI engineering
- LLM applications
- AI agents
- RAG
- MCP
- AG-UI
- AI evaluation

---

## Design

Responsible for:

- User experience
- User interface
- Design systems
- Branding
- Developer experience

---

## Operations

Responsible for:

- Infrastructure
- Deployments
- Automation
- Security
- Monitoring
- Repository administration

---

Capabilities evolve continuously.

New capabilities are introduced only when they provide long-term value.
